# GraphTrainer graph pass pipeline (default vs opt-in passes)

## Definition
In `aot_fx_trace` mode the traced train-step graph is run through a built-in pass pipeline controlled by `--compile.*` flags. The README splits it into **default, numerics-preserving passes** (graph cleanup, FSDP bucketing for comm/compute overlap, regional Inductor on tagged regions, CUDA graphs) and **opt-in performance passes** (full Inductor, numerics-changing fusions, async TP, CPU offload, selective remat, EP overlap). Passes can be disabled one by one by name for ablation.

## In torchtitan (grounded)
- Orchestration: [`construct_default_graph_passes`](../catalog/torchtitan/experiments/graph_trainer/passes.md#construct_default_graph_passes) assembles the list from [`compile_time_passes`](../catalog/torchtitan/experiments/graph_trainer/passes.md#compile_time_passes) (cleanup, memory policy, bucketing, EP overlap, async TP) plus [`final_inductor_compile_passes`](../catalog/torchtitan/experiments/graph_trainer/passes.md#final_inductor_compile_passes) and the [`cudagraph_pass`](../catalog/torchtitan/experiments/graph_trainer/cudagraph.md#cudagraph_pass); [`apply_graph_passes`](../catalog/torchtitan/experiments/graph_trainer/passes.md#apply_graph_passes) runs them, logging before/after graphs via [`tlparse_log_graph_pass`](../catalog/torchtitan/experiments/graph_trainer/debug_utils.md#tlparse_log_graph_pass). [`construct_mandatory_graph_passes`](../catalog/torchtitan/experiments/graph_trainer/passes.md#construct_mandatory_graph_passes) holds correctness passes that run even with optional passes off.
- Cleanup: [`canonicalize_graph_pass`](../catalog/torchtitan/experiments/graph_trainer/remove_noop_passes.md#canonicalize_graph_pass).
- FSDP overlap: [`joint_transformer_block_bucketing_reordering_pass`](../catalog/torchtitan/experiments/graph_trainer/fsdp_passes.md#joint_transformer_block_bucketing_reordering_pass) (always in the list), [`reassign_collective_pgs_pass`](../catalog/torchtitan/experiments/graph_trainer/fsdp_passes.md#reassign_collective_pgs_pass) (under [`enable_fsdp_ag_rs_overlap`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.enable_fsdp_ag_rs_overlap)), [`schedule_fsdp_comms_to_dense_regions_pass`](../catalog/torchtitan/experiments/graph_trainer/fsdp_passes.md#schedule_fsdp_comms_to_dense_regions_pass) (under [`enable_fsdp_dense_region_overlap`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.enable_fsdp_dense_region_overlap)).
- Async TP (micro-pipeline TP over symmetric memory): [`async_tensor_parallel_pass`](../catalog/torchtitan/experiments/graph_trainer/passes.md#async_tensor_parallel_pass), gated by core [`CompileConfig.enable_async_tensor_parallel`](../catalog/torchtitan/config/configs.md#CompileConfig.enable_async_tensor_parallel).
- Inductor: [`inductor_compilation`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.inductor_compilation) = `regional` (default: [`annotate_flex_attention_for_regional_inductor_pass`](../catalog/torchtitan/experiments/graph_trainer/inductor_passes.md#annotate_flex_attention_for_regional_inductor_pass) + [`regional_inductor_pass`](../catalog/torchtitan/experiments/graph_trainer/inductor_passes.md#regional_inductor_pass)) or `full` ([`full_inductor_compilation_pass`](../catalog/torchtitan/experiments/graph_trainer/inductor_passes.md#full_inductor_compilation_pass), terminal). [`numerics_changing_optim`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.numerics_changing_optim) adds [`annotate_rmsnorm_for_regional_inductor_pass`](../catalog/torchtitan/experiments/graph_trainer/performance_passes.md#annotate_rmsnorm_for_regional_inductor_pass).
- Switches: [`disable_passes`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.disable_passes) (exact pass-name match, e.g. `cudagraph_pass`, [`custom_codegen_pass`](../catalog/torchtitan/experiments/graph_trainer/custom_codegen.md#custom_codegen_pass)), [`enable_passes`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.enable_passes) (`--compile.no-enable_passes` skips all optional passes), [`debug_graph_passes`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.debug_graph_passes), and [`pass_pipeline`](../catalog/torchtitan/experiments/graph_trainer/configs.md#GraphTrainerCompileConfig.pass_pipeline) which selects a whole registered pipeline.

## Why it matters / when it applies
- **Numerics contract.** Regional Inductor is the default because FlexInnerAttention HOPs must be compiled to stay bitwise identical to the eager Trainer; `full` Inductor and `numerics_changing_optim` are faster but may change bitwise numerics, so they are opt-in.
- **Ablation workflow.** `--compile.disable_passes <a>,<b>` is the knob for attributing a step-time delta to one pass; `--compile.no-enable_passes` is the debugging floor. CUDA graphs can also be turned off with `--training.disable_cuda_graphs` (used in the GraphPP example).
- **TPU relevance.** `pass_pipeline` is the hook the TPU lane uses: [`TpuGraphTrainer`](../catalog/torchtitan/experiments/tpu/graph_trainer/tpu_graph_trainer.md#TpuGraphTrainer) registers a `tpu` pipeline ([`construct_tpu_transform_passes`](../catalog/torchtitan/experiments/tpu/graph_trainer/tpu_backend_pass.md#construct_tpu_transform_passes)) that replaces the Inductor/CUDA-graph tail with a TPU backend compile. CUDA-graph, Triton and symmetric-memory passes are GPU-only; the FX-level passes (memory policy, bucketing, chunking) are the transferable ideas.

**Doc vs code at this commit:** the `enable_fsdp_ag_rs_overlap` docstring refers to an `overlap_fsdp_ag_rs_pass`; no function by that name exists - the flag inserts `reassign_collective_pgs_pass` before bucketing.
